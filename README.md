# Real-Time Group Tracking System

A web application for motorcycle riders and road vehicles travelling in a group. Members share live GPS locations and see everyone on a single real-time map, so nobody has to call or message to find each other.

## Features
- Create or join a group with a group code
- Group leader (admin) controls: only the leader can add or remove members
- Live map with each member's name, vehicle type and last-seen time
- Alerts when a member stops for too long or falls behind
- Ride history with route replay

## Tech Stack
HTML, CSS, JavaScript, Leaflet.js, Node.js, Express.js, Socket.IO, PostgreSQL, OpenStreetMap, Browser Geolocation API
